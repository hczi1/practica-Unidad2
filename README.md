# 📖 Guía de Usuario - Cafetería La Chida

Bienvenido al sistema de gestión de pedidos de la **Cafetería La Chida**. Este documento proporciona instrucciones claras para que tanto clientes como empleados puedan utilizar la aplicación eficientemente.

## ✅ ¿Qué incluye la guía?

- Instrucciones paso a paso para usar la interfaz de usuario.
- Cómo personalizar pedidos (bebidas con ingredientes extra, postres).
- Cómo visualizar y modificar el carrito de compras.
- Opciones disponibles para empleados (gestión de productos e inventario).
- Botones de navegación y cierre de la aplicación.
- Notas sobre guardado automático de datos.

## 📂 Archivo PDF

Puedes encontrar el documento en el siguiente archivo PDF:

**guia_usuario_cafeteria.pdf**

> Asegúrate de incluir este archivo junto con la distribución de la aplicación para facilitar el uso por parte de los usuarios finales.

## 🧰 Requisitos

- Interfaz desarrollada en Python usando `Tkinter`.
- Archivos JSON necesarios para funcionar:
  - `productos.json`
  - `inventario.json`
  - `pedidos.json`

## 📝 Notas

- Los datos se guardan automáticamente.
- El sistema alerta si no hay stock suficiente de un ingrediente.
- La interfaz está pensada para ser simple y accesible.
